 Website Cases Report

This project contains three website case studies documented in `Website_Cases_Report_Revised.pdf`.

## Case Studies

### Case 5 – Digital Library Management Interface
A library website concept featuring:
- Book categories and book covers
- Author details and availability labels
- Search and filter interface elements
- Library rules
- Catalog information organized with CSS Grid and structured tables

### Case 9 – Bakery and Cake Shop Website
A bakery website concept featuring:
- Cakes, pastries, and cookies
- Custom cake designs
- Product prices and seasonal offers
- Store contact details
- A visually appealing color scheme and image galleries

### Case 19 – Adventure and Trekking Website
An adventure website concept featuring:
- Trekking routes and camping trips
- Difficulty levels and trip schedules
- Equipment checklists and safety guidelines
- Package prices
- Image overlays and distinct information panels

## Implementation Notes

The report describes creating a folder for the cases, writing website code for each case, and linking the pages to external CSS files.
